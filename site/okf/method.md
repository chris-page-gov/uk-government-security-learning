# How to use this catalogue

This independent public discovery edition covers the portal snapshot of 31 October 2026: **716 catalogue entries, 159 public pages and 557 entries marked Sign-in required**.

Use Source access and Topic to narrow the catalogue. Titles, displayed update dates and access notices come from the anonymous portal. Descriptions for sign-in entries are local navigation notes based on those public fields. They are not abstracts of the protected sources. Topic matches use explicit public-title rules. Suggested background is a local association, not evidence of what the protected source contains or requires.

For public pages, the excerpt is the public listing abstract, not a retained full document. Public-page links record references observed anonymously. No attachments are included or cleared for reuse. Update dates are page metadata, not event dates. Open the original source for its current information and access rules.

The glossary explains only terms supported by public evidence. A publisher-approved public abstract could provide more detail later, with explicit approval and provenance.
