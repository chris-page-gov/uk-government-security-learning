# Does WebMCP enforce our governance policy?

## Expose a controlled interface

**local-analysis**

WebMCP provides an experimental page-tool interface. Our tools return bounded evidence, citations and local analysis; the manual interface uses the same handlers.

Evidence: [WEBMCP-BOUNDARY](../evidence/WEBMCP-BOUNDARY.md).

## Apply governance outside the hint

**local-analysis**

A read-only annotation describes a tool; it does not establish the organisation's task authority. Enforce input limits, source boundaries and consent in the implementation, and retain human accountability for consequential activity.

Evidence: [WEBMCP-BOUNDARY](../evidence/WEBMCP-BOUNDARY.md), [AI-ACCOUNTABILITY](../evidence/AI-ACCOUNTABILITY.md), [AGENT-BOUNDARIES](../evidence/AGENT-BOUNDARIES.md).

## Directions for next work

- Inspect the actual tool inventory and schemas.
- Verify native execution separately from the AI host's callable-tool bridge.
- Treat source text and imported documents as untrusted data.

## What this does not establish

- Native browser support does not prove support in every AI host or browser.
