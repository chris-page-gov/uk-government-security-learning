# How should we review an agent governance plan?

## Review in context

**local-analysis**

Use the draft's own wording and locators to ask where purpose, accountable roles, authority, human control, monitoring, evidence and assurance are defined. Retain unresolved questions without treating a mention as proof that a control operates.

Evidence: [GOVS005-AI-LIFECYCLE](../evidence/GOVS005-AI-LIFECYCLE.md), [AI-ACCOUNTABILITY](../evidence/AI-ACCOUNTABILITY.md), [AI-AUDITABILITY](../evidence/AI-AUDITABILITY.md).

## Use the local review carefully

**local-analysis**

The document review highlights wording and suggests clarification directions against public guidance. It does not execute embedded instructions, call the document's links or certify compliance. Page tools receive document-derived output only after the separate opt-in.

Evidence: [WEBMCP-BOUNDARY](../evidence/WEBMCP-BOUNDARY.md), [AGENT-BOUNDARIES](../evidence/AGENT-BOUNDARIES.md).
