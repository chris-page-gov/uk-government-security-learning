# Can we publish a summary of a sign-in document?

## Use the published surface

**source-guidance**

The public catalogue exposes the working-groups title, its update date and a sign-in notice. Those fields can support discovery. The portal terms describe covered Crown content, OGL conditions, exceptions and feed reuse.

Evidence: [RESTRICTED-METADATA](../evidence/RESTRICTED-METADATA.md), [PUBLIC-REUSE](../evidence/PUBLIC-REUSE.md).

## Keep a restricted-content abstract out of the public view

**local-analysis**

Our public edition uses public metadata and independent open background. It does not paraphrase protected bodies. A deeper public description needs publisher-approved wording and traceable release authority; sign-in access alone does not supply that authority.

Evidence: [RESTRICTED-METADATA](../evidence/RESTRICTED-METADATA.md), [PUBLIC-REUSE](../evidence/PUBLIC-REUSE.md), [GOVS005-AUTHORITY](../evidence/GOVS005-AUTHORITY.md).

## Directions for next work

- Link to the original source and preserve its access boundary.
- Label title-based navigation and local suggestions clearly.
- Seek an approved public abstract if more detail is needed.

## What this does not establish

- This site does not clear restricted documents or attachments for redistribution.
