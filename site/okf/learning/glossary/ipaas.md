# iPaaS (integration platform as a service)

A managed cloud service for connecting applications and data, often through connectors, data mapping and workflow coordination. It is an integration capability; an organisation must still define ownership, permission and operating controls.

This is a local teaching definition grounded in the linked public evidence, not a new official government term.
