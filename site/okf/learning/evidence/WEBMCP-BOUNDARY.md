# Tools are an interface, not task authority

Evidence kind: **local-analysis**.

WebMCP lets a page register tools for agents to discover and execute. The draft includes tool annotations and security considerations for untrusted tool content. Our governance interpretation is that this interface does not establish an organisation's authority to perform a whole task, approve a disclosure or operate a government service.
