Understand the result
Source guidance explains the cited public text. Local analysis interprets it for a teaching problem. Synthetic examples illustrate a possible implementation.
A citation identifies the publisher, source, selected passage, locator, edition or observation date, text digest and reuse scope. Follow the original for its full current wording.
The catalogue includes 557 sign-in entries with public metadata only. Their protected contents and attachments are excluded. The selected evidence engine covers ten sources; the catalogue is a separate discovery layer.
Using documents and URLs
Review directions refer to extracted lines. A mention does not prove an operating control; a missing phrase does not prove an absent control. Check the original document and agree decisions with the relevant owner.
DOCX uses main-body and table text, excluding deleted revisions, comments and embedded files. PDF uses text only, up to 40 pages and the character limit. Extraction limits are shown with each import.
URL retrieval is browser-only, without credentials. Sign-in sources are not retrieved. A labelled stored excerpt may be used when live retrieval is unavailable.
