# Security learning pathways — public publisher

This repository contains only the reviewed public website artifact, exact-byte promotion evidence and the workflow that verifies and deploys it. The source repository remains private. Protected bodies, private findings, supplied source documents and account records are excluded.

The root website provides cited agentic-governance and governance-as-code learning, seven bounded WebMCP tools, browser-local document/URL review and an illustrated native walkthrough. Sign-in entries contain metadata only. The separately versioned 1.1.0 [AI and architecture companion](site/supplements/ai-and-architecture/index.html) adds public-source summaries, local proposals, a synthetic library example and 461 reference observations. The existing graph/tools remain frozen at 1.0.0 and do not index that companion. Historical walkthrough images retain their original identities.

The private source workflow assures the candidate. Its exact bytes are copied here without a rebuild. See promotion.json, site/release.json, site/site-manifest.json and site/licences/. Successful deployment is distinct from live browser acceptance.

Public sector information retains OGL v3.0 and source exceptions. Reader and parsing libraries retain their own notices. There is no blanket licence for the mixed corpus or implied government endorsement. Local teaching and synthetic checks do not establish official adoption or production compliance.
